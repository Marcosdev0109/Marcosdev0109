## Projetos em destaque

### [SkillMatch Web](https://github.com/Marcosdev0109/skillmatch-js) — projeto principal

Aplicação web que compara o perfil de um candidato com vagas de front-end, calcula compatibilidade, identifica habilidades faltantes e sugere prioridades de estudo.

`JavaScript` `ES Modules` `POO` `Fetch API` `localStorage` `HTML semântico` `CSS mobile-first`

- Motor de compatibilidade e ordenação por critérios.
- Interface responsiva com temas claro e escuro.
- Validação acessível, persistência local e estados de carregamento/erro.

### [Repo Finder](https://github.com/Marcosdev0109/js-buscador-de-repo)

Buscador responsivo que consulta a API pública do GitHub e apresenta os repositórios mais estrelados para cada termo pesquisado.

`JavaScript` `GitHub REST API` `HTML5` `CSS3` `Acessibilidade`

- Consumo assíncrono de API e tratamento de falhas.
- Estados de carregamento, resultado vazio e limite de requisições.
- Escape de conteúdo externo antes da renderização no HTML.

### [Titanic Pipeline ETL com Gemini](https://github.com/Marcosdev0109/Titanic.Pipline.ETL)

Experimento de dados que aplica um fluxo de extração, transformação e geração de narrativas ao dataset Titanic, integrando Pandas à API Gemini 2.5 Flash.

`Python` `Pandas` `ETL` `Jupyter Notebook` `Gemini API`

> Projeto experimental e educacional; as evoluções citadas no repositório ainda estão planejadas.

### [Podcast criado com IAs](https://github.com/Marcosdev0109/podcast-criado-com-ias)

Estudo guiado da DIO sobre orquestração de prompts e produção multimídia com ferramentas generativas, da criação do roteiro à edição do episódio.

`IA generativa` `Prompt engineering` `ElevenLabs` `Canva` `CapCut`
